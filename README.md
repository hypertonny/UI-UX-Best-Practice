# The 60km Snack & Medicine Run

HCI mid-term project, STET301.

Live site: https://hypertonny.github.io/UI-UX-Best-Practice/

## What this is

Campus is ~30km from anywhere that actually delivers, so getting groceries, medicine, or snacks
means a 4-6 hour round trip. This project is the full research + IA process behind that problem:
interviews, a card sort, a tree test, MoSCoW, and a DFV matrix. No UI screens, per
the brief, this is entirely research and sensemaking.

## Files

- `index.html` + `style.css` - the actual submission. Single scrolling page, plain HTML/CSS, no JS.
- `images/` - the empathy map, journey map, and IA tree, exported as PNGs and embedded in the page.
- `research-board.excalidraw` - the working file behind those three diagrams, made in
  [Excalidraw](https://excalidraw.com) (VS Code extension). Open it there to see/edit the originals.

## Process, roughly

1. Proto-persona (assumptions) -> interviews -> true persona, empathy map, journey map, pain
   point, user stories.
2. Feature list from the user stories -> card sort (open, then hybrid after the open version got a
   low response rate) -> V1 IA tree -> tree test -> pivot based on where people
   actually got lost.
3. MoSCoW on the full feature list, then a DFV matrix on the two features that were the closest
   call for the last Must-Have slot.
