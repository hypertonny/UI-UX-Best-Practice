## Overview

Students at our university face an unreliable transportation experience due to the lack of real-time location and arrival status for government buses they depend on.

This project documents an end-to-end UX research and information architecture process to address this challenge without jumping directly to high-fidelity UI screens.

## Project Structure & Phases

### 0. Observation Log
- Raw, real-world notes capturing student commuting behavior before formal research.

### Phase 1: Empathy and Definition
- **1A. Proto-Persona:** Initial assumptions prior to user interviews.
- **1B. User Research:** 3 in-depth interviews with university commuters (*Rajdeep, Yash, Parsad Kakad*).
- **1C. Research-Validated Persona:** Updated persona reflecting actual user needs.
- **1D. Empathy Map:** What students say, think, do, and feel.
- **1E. User Journey Map:** 7-stage commuter journey with an emotional curve pinpointing the lowest dip.
- **1F. Core Pain Point:** Information vacuum during the waiting stage.
- **1G. User Stories:** 4 grounded user stories defining core product needs.

### Phase 2: Ideate and Evaluate
- **2A. Feature Inventory:** 17-item content & feature inventory.
- **2B. Hybrid Card Sort:** Mental model clustering conducted with 5 students.
- **2C. V1 Information Architecture:** Initial 4-branch IA structure.
- **2D. Tree Testing & V2 IA:** 5-participant text-tree usability test identifying navigation failures and leading to the revised V2 IA.

### Phase 3: Prioritization
- **3A. MoSCoW Prioritization:** Categorization of all 17 features with a strict 4-item Must-Have MVP limit.
- **3B. DFV Matrix:** Desirability, Feasibility, and Viability evaluation settling the 4th Must-Have slot (*WhatsApp Alert Integration vs. Live Crowd Info*).

## Technical Details

- **Frontend:** Semantic HTML5 and Vanilla CSS3 only.
- **Design System:** Custom CSS variables, responsive typography (Inter & Lora), accessible cards, tables, and callouts.
- **No external JavaScript or frameworks.**
- **Diagrams:** Hand-crafted whiteboard style visual assets.
